# AI Stock Intelligence — Personal Release Contract

Scope: single-user personal deployment.

- ADMIN/OPERATOR multi-user authentication is intentionally postponed and is not a release blocker.
- Personal release prioritizes analysis quality, data freshness, storage safety, Android stability, and readable mobile UI.
- Automatic housekeeping may delete only explicitly disposable data. Protected analytical/history tables remain preserved.
- Android wrapper version identity must come from package metadata, not a stale hardcoded string.
- Any change after this release should be justified by a confirmed bug, data-quality issue, provider/runtime change, or an explicitly requested new feature.
